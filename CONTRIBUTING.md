# Contributing

This is a personal project, but fixes are welcome.

1. Open an issue or a pull request against `main`.
2. Run `pnpm test`, `pnpm run lint` and `pnpm run format` before pushing.
3. Use a Conventional Commit prefix (`fix:`, `feat:`, `chore:`).

Translations: copy `src/_locales/en/messages.json` into a new locale folder and translate the
`message` values.
